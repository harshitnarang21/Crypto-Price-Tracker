## Full Project Description (for README.md):

# 🚀 Crypto Price Tracker & Portfolio Simulator

A feature-rich Python application for tracking cryptocurrency prices, managing portfolios, and predicting price trends using machine learning.

## ✨ Features

- 📊 **Live Price Tracking** - Real-time cryptocurrency prices for top 20+ coins
- 💼 **Portfolio Management** - Track investments with automatic profit/loss calculations
- 🤖 **ML Price Predictions** - Linear and Polynomial Regression models for price forecasting
- 📈 **Data Visualization** - Interactive charts for price history, portfolio allocation, and comparisons
- 🔍 **Search & Discovery** - Find cryptocurrencies and view trending coins
- 💰 **Profit/Loss Tracking** - Real-time portfolio value and gain/loss calculations

## 🛠️ Technologies

- **Python 3.7+** - Core language
- **CoinGecko API** - Real-time cryptocurrency data
- **scikit-learn** - Machine learning models (Linear & Polynomial Regression)
- **matplotlib** - Data visualization and charts
- **pandas & numpy** - Data processing and analysis
- **requests** - HTTP API integration
- **colorama** - Terminal UI enhancements

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/crypto-tracker.git
cd crypto-tracker

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the application
python main.py
```

## 📋 Requirements

- Python 3.7 or higher
- Internet connection (for API calls)
- See `requirements.txt` for package dependencies

## 🎯 Key Capabilities

1. **Live Price Monitoring** - View current prices, 24h changes, and market caps
2. **Portfolio Tracking** - Add/remove holdings, track average buy prices, calculate P/L
3. **ML Predictions** - Get 1-3 day price forecasts with confidence scores
4. **Visual Analytics** - Generate charts for price trends and portfolio performance
5. **Search Functionality** - Find any cryptocurrency by name or symbol

## 📊 API Used

- **CoinGecko API** (Free Tier)
  - No API key required
  - Rate limit: 10-50 calls/minute
  - Endpoints: Markets, Price History, Search, Trending
